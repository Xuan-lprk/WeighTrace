# 隐私说明

本项目的目标是让支持的体脂秤可以在不注册厂商账号的情况下使用。

## App 处理的数据

- 蓝牙设备名称、iOS 分配的设备标识和秤广播中的设备信息；
- 本人及家庭成员的性别、身高、出生日期和参考体重；
- 体重、原始阻抗/ADC、公式估算结果和测量时间；
- 仅在调试页面内存中保留的最近蓝牙日志。

## 数据保存位置

App 不包含第三方统计 SDK。个人资料、设备设置和测量历史保存在当前设备的 App 沙盒中。Mac 版检查更新时请求 GitHub 的公开 Releases 信息；GitHub 会收到正常网络连接信息（例如 IP 地址），请求不包含个人资料、测量值或蓝牙日志。自动检查默认关闭，开启后在进入资料页时检查，当前会话内最多每天一次。

在 iPhone 或 iPad 上启用“自动写入 Apple 健康”后，用户选择的体重、BMI、体脂率和去脂体重会交给 HealthKit 保存。HealthKit 数据之后如何同步由用户的 Apple 健康和 iCloud 设置决定，不再只属于本 App 的本地存储。

Mac 版不请求 Apple 健康权限，也不会把 Mac 上的测量自动传到 iPhone。Mac 版只在前台连接体脂秤，并把资料、双 ADC 和测量历史保存在这台 Mac 的 App 沙盒中。

## 权限

- 蓝牙：发现、连接体脂秤并接收测量数据；
- 健康（仅 iPhone / iPad）：仅在用户主动启用时读取数据来源或写入所选指标；Mac 版不申请此权限。

App 不需要相机、定位或通讯录权限。Mac 的网络客户端权限用于版本检查；下载链接由浏览器打开。

## 删除数据

- 测量历史可在 App 的历史列表中侧滑删除；
- 对于由本 App 写入 Apple 健康且仍能定位到的关联样本，从 App 删除测量时会同时尝试删除；其他来源的健康数据需要在“健康”App 中管理；
- 删除 App 会移除其沙盒内的资料、设置和历史，但不会自动删除已经写入 Apple 健康的数据。

Mac 版没有 HealthKit 恢复通道。可在“我的 → 备份与导出”生成完整 JSON 文件，保存到本地或用户选择的 iCloud Drive；重装后选择文件并确认合并，即可恢复备份中的本地资料、测量与阿福参考。备份文件未加密，包含健康资料。导入不会恢复蓝牙绑定或健康权限，也不会向 Apple 健康写入历史数据。没有提前导出的文件时，删除数据容器后无法自动恢复。
