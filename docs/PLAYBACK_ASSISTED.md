# 数据回放与抱物称重

## 回放这段时光

入口：“趋势 → 选择成员 / 时间范围 / 指标 → 播放这段时光”。深色青蓝渐变舞台展示原始测量数字、展开曲线和当前光点，日期、条件标签、备注及 ADC/算法/资料变化随记录切换。

- 支持播放、暂停、进度拖动、0.5× / 1× / 2×。
- 离开页面、进入后台或记录集合变化时暂停；播放结束后再次播放会从头开始。
- 空数据不播放；单条记录只供查看；缺测日期不会产生虚构测量。
- 体脂和 BMI 按计算条件分段，体重连接已有原始记录。点开事件卡可查看原始详情。
- 遵循系统“减少动态效果”；光晕为静态背景，播放使用单个可取消任务，不使用逐点 Timer 或持续 60 Hz 重建。
- 长历史的图表最多绘制约 300 个抽样点和当前原始点，但进度仍逐条访问全部原始记录。坐标范围固定于整段数据，减少播放中的缩放跳动。

## 抱猫、行李或包裹称重

入口在“测量”首页底部。先建立名称及类型档案，连接秤后开始：

1. 先离秤，等待低于 1 kg 的读数。
2. 本人单独上秤，等待稳定读数作为基线。
3. 离秤后，由同一个人抱着对象再次上秤。
4. 稳定读数减去基线，得到对象的粗略重量；结果自动保存。

这种模式只使用稳定体重，不等待阻抗，也不计算对象或抱物人的体脂。两次读数分别保存，便于核对。重复稳定包只保存一次；总重不高于基线时要求离秤重试第二步；两步相隔超过十分钟会要求重做基线；中途断线会清除未完成基线。两种实验模式（三次检查和抱物称重）不能同时开启。

进行中的模式在首页有入口；离开页面不会自动结束采集，退出时需明确点击按钮。完成后请退出并离秤，再恢复普通称重。它与三次检查一样依赖实体秤报告低体重事件，秤若不发送该事件，流程会等待，需进一步用真秤验收。

对象档案和记录独立保存，可切换对象查看趋势和删除单次记录，JSON 备份会带走对象和记录。它们不进入日常身体历史、身体趋势和 Apple 健康。当前身体测量 CSV 不包含抱物记录，完整档案请用 JSON。

两次称重误差会叠加，重量只能作粗略参考。需保持衣物和随身物品一致，不超过设备额定承重；宠物不配合时停止。程序无法确认两次是否为同一个人或实际抱了什么。

## 验证

扩展 `scripts/check-trends-backup.sh` 的合成测试覆盖：稳定/不稳定包、前后离秤、防重复、负差值重试、超时、断线、对象关联完整性、JSON 合并往返，以及空/单条/多条回放进度边界。实体称重、后台暂停、触控拖动、减少动态效果和多设备视觉表现仍需交互验收。
