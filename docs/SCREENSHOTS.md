# 截图演示与语言

## 在 App 中使用

1. 打开“我的 → 显示与演示”，选择“跟随系统 / 简体中文 / English”。界面会重新创建，尚未保存的页面输入不会保留，因此请先完成编辑再切换。
2. 点击“截图演示模式”。不需要体脂秤，也不必先配对。
3. 演示中有 35 天虚构本人记录、虚构家庭成员和 18 条虚构阿福参考；可浏览测量、历史、趋势、回放及双 ADC 对照。
4. 顶部始终标明“演示数据”，点击“退出演示”返回真实资料。

演示使用独立的临时 UserDefaults 域，退出时移除。真实资料、历史、参考和配对信息不被替换；演示不创建蓝牙管理器、不访问 HealthKit。真实蓝牙会在进入演示时暂停，退出后按进入前的连接状态尝试恢复。

演示中的设置表单禁用，避免误申请权限、触发更新检查或改变设置。要拍另一种语言，先退出演示、切换语言，再重新进入。生成的数据基于固定曲线，不使用随机真实用户信息；日期按当前日期排列，让默认 30 天筛选始终有内容。参考值是合成样本，不表示阿福算法的真实表现。

## Xcode 中使用

- 打开 `体脂秤/Views/ScreenshotDemoView.swift`，启用 Canvas，运行名为“截图演示”的 `#Preview`。
- 也可以在 **Product → Scheme → Edit Scheme → Run → Arguments → Arguments Passed On Launch** 添加 `--screenshot-demo`。运行后直接进入同一套演示界面；取消该参数即可恢复正常启动。
- 模拟器可通过 **File → Save Screen** 保存截图。真机按系统截图快捷键即可。

建议拍摄：测量首页、30 天体重趋势、历史回放、单次双 ADC 对照。保留“演示数据”标记，不把合成对照作为准确性证据。

语言切换不改生日、成员名字、用户备注或已保存的历史文本；系统蓝牙/健康权限弹窗仍由系统语言设置决定。
