# 秤迹 WeighTrace — Mac 测试版安装

需要 macOS 15.6 或更新版本，支持 Apple 芯片和 Intel Mac。无需 Xcode，也无需开发者账号。

## 先下载安装包

打开本项目的 [GitHub Releases 发布页](https://github.com/Xuan-lprk/smart-body-scale-IOS/releases)，选择需要的版本，在 **Assets** 中下载 `AFU-Scale-Mac-…-test.dmg`。`Source code (zip)` 和 `Source code (tar.gz)` 是源码，不是安装包。如果没有 DMG，该版本暂不能按本文直接安装。

请同时阅读该版本的发布说明：仓库首页可能包含尚未打包的新功能。当前仅验证 `AFU-WL-TZ-A1 / category=2 / subtype=7`，不保证其他型号兼容。

## 安装与首次连接

1. 打开 DMG，把“WeighTrace（秤迹）”拖入 Applications（应用程序）。旧测试包中可能仍显示“体脂秤”。
2. 从“应用程序”打开 WeighTrace，不要直接在 DMG 内运行。
3. 当前是未经 Apple 公证的测试版。如果 macOS 阻止打开，在尝试打开后进入“系统设置 → 隐私与安全性”，核对应用来源，再使用系统提供的“仍要打开”。不需要关闭 Gatekeeper 或执行终端命令。
4. 允许蓝牙，关闭手机阿福及其他正在连接秤的程序，然后踩秤唤醒并连接。

若系统提示恶意软件或提供的文件来源不符，请停止安装并联系发布者。不同系统版本的提示可能不同；如果没有允许按钮，请把准确提示发给发布者。

## 更新与保留记录

升级前，先在“我的 → 备份与导出”保存 JSON 备份，再退出 App、下载新版并覆盖“应用程序”中的旧版。不要把旧版与新版同时运行。

从旧名“体脂秤”升级时，新包为 `WeighTrace.app`，Finder 不一定自动覆盖旧名字的 App。先退出旧版，安装新版并确认记录仍在，再将旧 App 移到废纸篓；不要使用卸载清理工具。Bundle ID 与数据键名未改，仍使用相同的数据容器。安装包暂保留 `AFU-Scale-Mac-` 前缀供旧版更新检查识别。

测量资料保存在这台 Mac 的 App 容器中。正常覆盖安装同一 Bundle ID 的新版本会继续使用原来的容器；不要使用卸载清理工具删除数据。Mac 数据不会自动同步到手机。JSON 文件包含个人健康资料且未加密，请妥善保存；需要时可在同一入口选择文件并确认合并恢复。

“自动检查更新”仅获取 GitHub Releases 的公开版本信息，不发送体重、个人资料或蓝牙日志。发现新版后可以打开下载页面，下载并覆盖安装。当前测试版尚不支持自动替换 App 和自动重启。

## 遇到问题

搜不到秤时，检查蓝牙权限、秤是否亮屏，并确认手机阿福、其他电脑或 CLI 已断开。Mac 版需要 App 在前台连接，不支持 Apple 健康。

仍有问题可到 [Issues](https://github.com/Xuan-lprk/smart-body-scale-IOS/issues)反馈：提供 App 版本、macOS 版本、芯片类型、秤型号、复现步骤及准确报错。公开前请遮住姓名、生日、健康数值和蓝牙设备标识，不要直接上传完整 JSON 备份。
