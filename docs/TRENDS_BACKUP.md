# 趋势与数据备份

## 趋势

底部“趋势”支持按成员、30 天 / 90 天 / 全部、体重 / 体脂 / BMI 筛选。尚未配对也可查看已经恢复的记录。原始记录仍在“历史”中保留。

- 体重圆点是原始测量；绿色实线是每日中位数；橙色虚线是过去 7 个日历日内有记录日期的日中位数平均。
- 同一天称多次不会增加这一天的统计权重；没有测量的日期不补值、不伪造记录。单日数据也会显示，但不计算首末日差。
- 趋势按设备当前时区划分日期；跨时区后每日归组可能变化。
- 体脂、BMI 不跨不同算法、ADC 或资料快照连接线段，不平均不同算法的体脂。标记与列表显示相邻档案的变化，不代表真实设置修改时刻。
- 点击/拖动图表后可进入最近的原始测量详情，包括已有阿福对照。缺少资料快照的旧记录不能还原全部变化。
- 本轮只展示 App 本地历史，尚未把 HealthKit 外部来源样本加入同一趋势；记录没有实体秤快照，因此不会推断换秤事件。

## 备份与恢复

“我的 → 备份与导出”提供：

1. **JSON 完整备份**：本人资料、家庭成员、测量主体、双 ADC、算法版本、资料快照及阿福参考（含可选字段与备注）。
   新增的三次检查报告、日常测量标签与备注也保存在 JSON 中；老文件没有这些可选字段时仍可读取。
2. **CSV 分析表**：每次测量一行，包含主要指标、双 ADC、计算资料和阿福体重/体脂参考。CSV 不能恢复完整档案，原始详情以 JSON 为准。
3. **JSON 导入预览**：分别展示新增、相同 UUID 重复、内容冲突数量。展开可查看冲突摘要。默认保留本机值；明确开启覆盖后，冲突采用备份内容。

恢复按 UUID 合并；同一次测量的阿福参考也检查关联身份，避免产生两个参考。重复导入不重复增加记录。未出现在备份中的本机记录会保留。导入前先校验格式、版本、数值、重复 ID 与参考关联，再更新本地存储。

本人使用固定 UUID，仅应导入属于本人的备份；不同人的家庭成员即使同名也不会自动合并。备份允许历史记录继续引用已被移除的成员，趋势中仍能找到这些历史分组。备份不包含 HealthKit 权限、配对设备身份、更新设置和默认 ADC 偏好，不会扫描健康数据库，也不会重新向 Apple 健康写入历史。

覆盖冲突前建议先导出本机 JSON；备份为未加密文件，可以使用系统保存面板主动存到本地或 iCloud Drive。它是手动文件备份，不是自动云同步。单次导入限制 50 MB。

## 文件格式

JSON 的 `format` 为 `afu-scale-backup`，`schemaVersion` 当前为 1。日期使用 Foundation Codable 默认的数值编码（自 2001-01-01 UTC 起的秒数），保留浮点时间精度；CSV 日期使用 ISO 8601。遇到未知版本会拒绝导入，不猜测字段含义。字段扩展时需要增加版本兼容处理。

## 验证

`bash scripts/check-trends-backup.sh` 使用合成数据验证 JSON 精度、重复导入、冲突处理、坏版本/重复 UUID/孤立参考拒绝、CSV 引号和公式转义、每日中位数和缺测日期、7 日趋势与 ADC 条件隔离。实体设备的文件选择器、iCloud Drive 和真实健康数据需单独交互验收。
