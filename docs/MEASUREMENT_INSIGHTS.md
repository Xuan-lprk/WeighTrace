# 测量解读与本周回顾

## 入口

- 测量成功预览、历史测量详情：**读懂这次测量**。
- 趋势顶部：**本周回顾**，随成员选择切换。回顾固定为当前周，不跟随下面的 30 / 90 天、指标筛选。
- 回顾详情底部可展开本周和上周的原始记录，打开测量详情检查依据。
- 「我的 → 显示与演示」里的演示模式含虚构历史与测量标签，可用于预览和截图。

## 统计口径

统计只使用同一成员的本地体重记录；未归属成员不进行聚合。不读取或混合 Apple 健康图表数据，不修改任何原始测量、算法或健康样本。相同 UUID 只计一次，不同 UUID 即使时间相同仍保留为不同原始记录；每日中位数降低重复称重的影响，但不等同于重复记录检测。

1. 排除未来记录、非有限值和非正体重。
2. 按设备日历与时区分日，每日先取体重中位数，再按有记录的日期等权平均。缺测日期不补零或插值。
3. 单次解读以该次测量时间为截止点，比较当日及前 6 天，与再往前的 7 天；历史记录不会利用此后的测量产生结论。
4. 周回顾以周一零点为起点，与上一个完整周比较；语言选择不改变周一这一规则。本周可能尚未结束，界面始终注明「截至今天」。
5. 两段时间各至少有 3 个不同记录日，才展示平均值差异。该门槛是产品上的数据充足性约束，不是医学有效性标准。
6. 差值为本期减前期，不将体重下降或上升默认评价为好坏。原始体重范围与中位数均值分别注明。

## 数据质量与解释边界

- 有效阻抗沿用当前项目的 100–1500 Ω 判定。旧记录无有效阻抗时，体重仍可统计，已有体脂不能作为有效 BIA 结果解读。
- ADC、算法和资料快照变化来自相邻记录，不是实际设置操作的精确时间。缺少快照时明确提示无法完整识别。
- 测量标签由用户填写，可以多选；没有标签表示未知，不推断空腹、运动、饮食或造成变化的原因。
- 页面「本地档案中已有此记录」表示记录出现在当前本地历史中，不等于独立文件备份，也不代表 Apple 健康写入成功。健康同步沿用现有流程，Mac 不访问 HealthKit。
- 所有说明由本地规则生成，无网络模型、无上传、无诊断或饮食处方。

## 验证

`bash scripts/check-trends-backup.sh` 包含统计测试：成员隔离、UUID 去重、按天等权、3 日门槛、未来数据排除、历史截止、缺失元数据、标签、跨年和夏令时边界。

手动检查：首次测量空状态、满三天及不足三天、中英文与大字体、iPhone 窄屏与 Mac 窗口缩放、修改标签后刷新、切换成员，以及旧记录缺失 ADC 的提示。截图演示数据仅用于视觉验证，不能代替实体秤测试。
