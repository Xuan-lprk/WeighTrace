# 更新日志

这里记录用户能够感知的功能变化。尚未发布的改动先放在“开发中”，发布版本时再补充版本号和日期。

## 开发中 — 1.7 (13)

下一次发布统一使用 App 版本 `1.7`、构建号 `13`、GitHub 标签 `v1.7`。早期 `V1.6.9` 标签是命名误写；本轮修复合并进入 1.7，先前本地 1.6.1–1.6.3 测试包不作为独立正式版本发布。

### 修复

- 三次检查支持读数下降至少 30 kg 后自动识别离秤；保留低于 1 kg 的判断及手动确认。下降读数只用于分隔测量，清空旧 ADC，重新上秤后必须再次收到稳定体重和有效阻抗；完成三次后不再解锁。

- 连接订阅 FFB2 成功后，向 FFB1 发送与 CLI 一致的 D0 初始化命令，包含时间、当前资料和开启阻抗测量标志；三次检查按选定成员初始化。新增 CLI 字节一致性与实际协议包测试。
- 无效阻抗包不再触发实时记录保存；体重稳定但未取得阻抗时显示等待提示。旧记录缺少有效阻抗时显示说明，BMI 回退公式单独标记版本；不修改既有历史数值。
- 三次检查显示当前采集体重、稳定状态和有效阻抗数量，避免只有 0/3 而无法判断等待环节。
- 更新检查兼容 `WeighTrace1.6-9.dmg` 和旧的 `AFU-Scale-Mac-…-test.dmg`，以包文件里的版本和构建号比较，避免 `V1.6.9` 标签被误认为 1.6.9 而实际包是 1.6 (9)。失败时显示 HTTP 状态或系统错误代码，并提供发布页入口。

- 拆分 ADC 差异图表的复杂类型推断表达式，解决 GitHub Actions 的 Xcode 26.4.1 在 iOS 模拟器构建时报类型检查超时的问题。
- Mac 更新检查改用重命名后的 WeighTrace 仓库地址，并同步调整发布页 URL 校验；更新区域显示当前版本与构建号。

- 趋势页新增 Apple 健康图表，读取体重、体脂率与 BMI，沿用时间和指标筛选，并按来源分线。健康数据仅显示为本人，不拼凑完整身体成分、不重复写回；与本地统计分开，避免重复计数。进入趋势、返回前台或下拉时刷新，可主动申请读取权限。
- 主页右上角连接按钮改为连接状态面板，显示设备、连接情况、重新搜索和发现设备；已连接时不再表现为无响应。
- 三次测量检查允许手动确认已经离秤，兼容不发送零体重包的秤；每次确认清空待采集数据，仍要求新稳定体重和双路阻抗，阻止重复包直接计数。测量状态下也可进入检查。

### 新增

- 新用户首次启动需填写本人性别、身高和出生日期，表单不预选资料；完整确认后才进入主界面并初始化蓝牙与健康服务。保留已有有效资料，备份恢复和截图演示兼容新流程。
- 截图演示模式：独立虚构资料、35 天趋势和双 ADC 参考样本，不连接蓝牙、不访问 Apple 健康、不改动真实记录；支持 Xcode Preview 和 `--screenshot-demo` 启动参数，见[截图指南](SCREENSHOTS.md)。
- “我的 → 显示与演示”新增跟随系统、简体中文和 English 语言选择，同时统一代码生成文字与 SwiftUI 界面的语言。
- 数据回放：趋势筛选结果可播放，包含深色渐变舞台、动态数字、渐进曲线、光点和事件卡，支持暂停、拖动、速度切换及减少动态效果。
- 抱物称重：独立宠物/行李/包裹档案，两次稳定体重相减，保存粗略重量及原始读数；含离秤门控、断线/超时处理、防重复与独立历史曲线。
- JSON 备份扩展对象档案及抱物记录，保留旧文件兼容；实验不写入身体趋势或 Apple 健康。
- 三次测量检查：按离秤分隔采样，保存体重/双 ADC/阻抗与体脂重复性报告；实验不写入日常历史和 Apple 健康，报告随 JSON 备份保留。
- ADC 差异地图：按成员显示三套体脂曲线和有符号误差，点选查看条件；不合格参考可显示但不进入推荐。
- 自定义首页最多三项指标、同成员前后体重差、指标来源提示、测量条件标签和备注；历史按标签筛选，JSON/CSV 包含标注。
- 历史重算按测量时年龄计算；没有资料快照的参考不再参与 ADC 推荐统计。
- 趋势页：按成员、30 天 / 90 天 / 全部、体重 / 体脂 / BMI 筛选；体重保留原始点并展示每日中位数与 7 日趋势，支持选择记录查看详情。
- 计算条件变化标记：识别相邻测量的 ADC、算法和资料快照差异；估算曲线按连续条件分段。
- “我的 → 备份与导出”：完整 JSON 备份、按 UUID 合并恢复、冲突数量与明细预览、CSV 分析表；文件恢复不触发 HealthKit 写入。
- 无需先配对即可访问趋势、历史及备份入口，便于重装后恢复。
- 新增合成数据回归脚本并接入 CI，覆盖备份往返、重复与冲突、异常数据、CSV 和趋势统计。
- Mac 测试版 DMG 打包脚本和朋友安装说明，无需接收者安装 Xcode。
- Mac 资料页增加手动/可选自动检查 GitHub Releases，发现新版后打开下载页；尚不自动替换 App。
- Mac Catalyst 支持：
  - 复用 iPhone / iPad 版已经验证过的 CoreBluetooth 协议解析、测量状态机和双 ADC 记录；
  - 支持在 Mac 前台扫描并连接 AFU-WL 体脂秤，将个人资料和测量历史保存在 Mac App 沙盒；
  - Mac 版不请求 Apple 健康权限，资料页和测量预览改为明确的本地保存提示；
  - 为 Mac 单独配置 App Sandbox 与 Bluetooth 权限，iPhone / iPad 继续使用原有 HealthKit 权限；
  - 新增 Android 原生移植路线说明，但本轮未创建 Android 工程。
- 测量完成预览：
  - 每次稳定测量保存后立即展示体重、BMI、所选 ADC 与两路 ADC 的估算结果；
  - 可直接保留记录，或在确认后删除本地记录、关联的阿福对照以及本 App 写入 Apple 健康的样本；
  - 历史列表侧滑删除也使用相同的联动删除规则；
  - 若 Apple 健康仍在写入，会先等待写入结束再执行删除，避免残留数据。
- 卸载后恢复本地测量：
  - 新写入的 Apple 健康样本会附带本 App 的完整双 ADC 测量档案；
  - 使用相同 Bundle ID 重装并重新授权后，可在“我的资料 → Apple 健康”恢复本地历史；
  - 未开启健康同步、用户删除了健康样本或更换 Bundle ID 时无法恢复。
- ADC 1 / ADC 2 对照实验：
  - 新测量会同时保存两路原始 ADC 和换算阻抗，不再只保留当时选中的一路；
  - 支持从系统图片选择器多选阿福截图，并使用 Vision 在设备本地识别；
  - OCR 结果先进入可编辑表单，必须由用户核对体重、体脂和测量时间后才能保存；
  - 没有截图时也可手动录入阿福体重、体脂及水分、肌肉、骨量等可选指标；
  - 同一次测量并排显示阿福、ADC 1 和 ADC 2 的结果与差值；
  - 汇总体脂平均偏差、中位偏差、MAE 和 RMSE；
  - 只有时间差不超过 30 分钟、体重差不超过 0.2 kg 的记录参与统计建议；
  - 至少累计 10 个不同日期的合格对照后，才根据 MAE 给出 ADC 建议。
- Apple 健康数据来源识别：
  - 读取最近一年的体重、BMI、体脂率和去脂体重；
  - 显示来源 App、识别到的品牌、最近记录时间和样本数；
  - 当前包含华为、小米、Withings、Garmin、RENPHO、Eufy、InBody、欧姆龙、Fitbit / Google、Fitdays、OKOK、Feelfit 和 AiLink 的名称识别。
- 跨来源重复体重提示：
  - 检测不同 App 在 5 分钟内写入、且相差不超过 0.1 kg 的体重；
  - 展示每条记录的来源、时间、数值、时间跨度和体重范围；
  - 只提示疑似重复，不会自动删除或修改 Apple 健康。
- 新增“我的资料 → 跨体重秤数据 → 查看健康数据来源”入口。

## 1.6 — 仓库基线

- 读取已验证的 `AFU-WL-TZ-A1 / subtype=7` 体脂秤。
- 支持双 ADC 选择和本地身体成分估算。
- 支持本人资料、家庭成员、本地历史和设备身份绑定。
- 支持将体重、BMI、体脂率和去脂体重写入 Apple 健康。
- 不包含账号、广告、网络请求或第三方统计 SDK。
